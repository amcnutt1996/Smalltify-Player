# Decisions

How each choice was made: **User** means you decided it in chat, **Orch** means the orchestrator decided, and **Agent** means a build agent decided it and the orchestrator accepted. Every decision after you stepped away is marked *(autonomous)*.

With event waiting the window sleeps until there is input; background threads wake it with `Rwake_up` (via `window_wake`), which replaced `glfwPostEmptyEvent()`. |

| 10 | Polling: the UI ticks at 1 Hz from local interpolation; the Web API is fetched every 5 s while playing, at the predicted end of each track, and immediately after your own commands. | 18 | **Spotify Soloist replaces librespot** as the local "this computer" Connect device | User (+ Orch for the details) | It is Spotify's official headless client (Aug 2026; macOS/Windows since Oct 2026) and uses the same engine as the Spotify apps, so it gets no audio-key refusals. | 19 | Soloist is **downloaded at runtime** from `soloist-builds.spotifycdn.com` into `<app>/soloist/`, not bundled | Orch *(autonomous)* | Spotify's docs forbid redistributing Soloist binaries. | 20 | Soloist key read from `.env` as `SOLOIST_API_KEY=`; data and cache go to `<app>/data/soloist{,-cache}` with a 100 MB cache cap (the minimum Soloist allows) | Orch *(autonomous)* | Same place as the client ID. The cap keeps the folder small. The key is passed to Soloist only as an argument (Spotify's documented limit) and is never logged. |
| 21 | ~~Blocking pairing screen~~ → **pairing happens in the player**: unpaired, Soloist runs only while another device of the account is online (from the poller or a device list), with one dismissible tip naming that device; it stops after 10 min without one. | 22 | ~~Skip buttons~~ → no skip flow: the app never nags for the key or pairing. Devices → "Enable playback on this computer" opens the key screen (Back returns) | User | The app is a remote first; local playback appears once possible. |

| 29 | **macOS app bundle** `build/dist/Smalltify Player.app` (id `com.smalltifyplayer.app`, 0.1.0, macOS 13+, local-network usage text + `_spotify-connect._tcp` Bonjour key).
